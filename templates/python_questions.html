❓ Python Interview Q&A

Click on any question to reveal answers and real-world examples.

1. What is the difference between Lists and Tuples?
Lists are mutable (can be altered after creation), slower, and use more memory. Tuples are immutable (cannot be modified), faster, and memory-efficient. 
my_list = [1, 2, 3]   # Mutable\nmy_tuple = (1, 2, 3) # Immutable
🐍 Real-World Example: A **List** is like a grocery shopping list where you can add or cross off items as you walk through the store. A **Tuple** is like your passport passport number or birth date—once issued, it cannot change.
2. What is PEP 8?
PEP 8 stands for Python Enhancement Proposal 8. It is the official style guide manual for writing clean, readable, and consistent Python source code.
🐍 Real-World Example: Think of PEP 8 like traffic laws. The cars (code) will still run without them, but enforcing common rules prevents chaotic pile-ups and helps everyone navigate seamlessly.
3. Explain the difference between Python's arrays and lists.
Python **Lists** can hold objects of completely different data types (heterogeneous). The standard `array` module requires all entries to belong strictly to the exact same primitive type (homogeneous).
🐍 Real-World Example: A **List** is like a generic storage chest where you toss in clothes, tools, and books together. An **Array** is an egg carton that explicitly only holds items of the exact same size and structure.
4. What is Python's GIL (Global Interpreter Lock)?
The GIL is a mutex barrier lock ensuring that only a single native thread executes Python bytecodes at any given moment, preventing race conditions but limiting multi-core CPU thread scalability.
🐍 Real-World Example: A busy library with 4 computer terminals but only **one single mouse**. Even if 4 users sit down at once, only one person can click or input a command at a time.
5. How is memory managed in Python?
Python handles memory allocation dynamically through a private heap space managed by an internal controller, cleanups are triggered automatically using **Reference Counting** and a generational **Garbage Collector**.
🐍 Real-World Example: A restaurant table cleanup service. As soon as a table's guest count drops to zero, a busser clears the table instantly so new guests can sit down.
6. What are Python Decorators?
Decorators are wrapper functions that dynamically extend or alter the behavior of a target function without directly altering its original source code block. 
@my_decorator\ndef custom_func():\n    pass
🐍 Real-World Example: Wearing a raincoat. You are still the same person with the same basic behaviors, but you've added an outer layer that gives you the extra ability to resist water.
7. What is the difference between 'is' and '==' operators?
The `==` operator evaluates whether the **values** of two objects are equal. The `is` operator evaluates whether both variables point to the exact same object location in memory (**identity** check).
🐍 Real-World Example: Two identical copies of the same book. `==` checks if they contain the same text (True). `is` checks if they are literally the exact same physical copy in your hand (False).
8. What are Generators and how do they save memory?
Generators are functions that return an iterable sequence lazily using the `yield` keyword instead of `return`. They compute elements one at a time on demand rather than storing the entire list in memory.
🐍 Real-World Example: An on-demand streaming service like Netflix. It streams the specific minute of video you are watching right now, rather than downloading the entire multi-season series onto your hard drive before playing.
9. Explain List Comprehension.
A concise syntactic shorthand notation for deriving new lists out of existing iterable structures using single-line declarations. 
squares = [x**2 for x in range(10)]
🐍 Real-World Example: Instead of saying: "Go to the closet, open it, look at every shirt, pick the red ones, and place them on the bed," you simply say: "Bring me all the red shirts from the closet."
10. What is the purpose of `*args` and `**kwargs`?
- `*args` passes a dynamic, variable-length positional argument list to a function.
- `**kwargs` passes a dynamic, variable-length dictionary of keyword arguments.
🐍 Real-World Example: `*args` is like bringing a generic box filled with an unknown number of tools to a job. `**kwargs` is like bringing that box, but every single item inside is clearly labeled with its specific purpose.
11. What is the difference between Shallow Copy and Deep Copy?
- **Shallow Copy** creates a new outer collection object but copies references to its nested items.
- **Deep Copy** duplicates everything recursively, creating a completely independent copy of both the collection and its nested content.
🐍 Real-World Example: A **Shallow Copy** of a house blueprint clones the walls, but both blueprints still share the exact same physical key to the front door. A **Deep Copy** creates an entirely separate house with its own brand new keys.
12. Explain the use of the `with` statement and context managers.
The `with` statement simplifies resource handling by ensuring that cleanups, like closing files or releasing database locks, are executed automatically even if errors occur. 
with open('file.txt', 'r') as f:\n    data = f.read()
🐍 Real-World Example: Like renting a hotel room that automatically locks the safe and turns off all lights the moment you check out, ensuring no resources are left open or exposed.
13. What are lambda functions in Python?
Lambda functions are small, single-line anonymous functions defined without a name using the `lambda` keyword. 
multiply = lambda x, y : x * y
🐍 Real-World Example: A disposable paper cup. You throw it together quickly for a single, immediate drink and discard it right after use, rather than washing a permanent ceramic mug.
14. How do `break`, `continue`, and `pass` statements differ?
- `break`: Terminates the current loop completely.
- `continue`: Skips the rest of the current iteration and jumps to the next cycle.
- `pass`: A null statement used as a placeholder where code is syntactically required but no action is needed.
🐍 Real-World Example: Reading a book line-by-line: **break** means closing the book and walking away. **continue** means skipping a boring sentence to read the next line. **pass** means reading a blank placeholder page and moving on without pausing.
15. What are namespaces and scopes?
A **Namespace** is a mapping system that ensures every variable name is unique. **Scope** defines the area of code where a specific namespace can be directly accessed (Local, Enclosing, Global, Built-in).
🐍 Real-World Example: The name "John". Inside your family scope, calling "John" clearly refers to your brother. In a global city scope, you need to use his full address to identify him uniquely.
16. What is the difference between `__init__` and `__new__`?
- `__new__` is the actual creator method that builds and returns a brand-new blank instance of a class.
- `__init__` is the initializer method that receives that instance to set up its initial attributes and values.
🐍 Real-World Example: `__new__` is the construction crew framing the physical walls of a brand new house. `__init__` is the interior designer moving in to paint the rooms and place the furniture.
17. Explain method resolution order (MRO) in Python.
MRO defines the exact sequence Python uses to search for a method or attribute across complex multiple inheritance class hierarchies. It is calculated using the C3 Linearization algorithm.
🐍 Real-World Example: A chain of command. If an intern doesn't know how to handle a task, they look up to their team leader. If the leader doesn't know, it goes to the manager, then the director.
18. What are Dunder (Magic) methods?
Dunder (Double Under score) methods are built-in hooks like `__str__` or `__add__` that allow you to define how your custom objects behave with built-in operations (like printing or math).
🐍 Real-World Example: Teaching a custom robotic vehicle object what to do when someone presses the standard universal "+" button on a controller.
19. How do you implement abstraction in Python?
Import the `abc` module and use the `@abstractmethod` decorator to create abstract base classes that enforce specific structure across child subclasses.
🐍 Real-World Example: A blueprint for a steering wheel. It dictates that every car *must* have a functional turn method, but leaves it up to each manufacturer to decide whether it uses hydraulic or electronic steering.
20. What is the purpose of `self` in Python classes?
`self` represents the specific instance of the class currently invoking a method, allowing individual objects to access and modify their own unique data fields.
🐍 Real-World Example: A name tag that says "My name is...". When Person A reads it, it refers to Person A. When Person B reads it, it refers to Person B.
21. What are closures in Python?
A closure is an inner function that remembers and retains access to variables from its outer enclosing scope, even after the outer function has finished executing.
🐍 Real-World Example: A spy carrying a secret message from headquarters. Even after leaving the base (outer function exits), the spy still holds onto that message wherever they go.
22. Explain Python's built-in `map`, `filter`, and `reduce` operations.
- `map`: Applies a function to every item in an iterable.
- `filter`: Extracts items that pass a specific condition check.
- `reduce`: Combines all items into a single summary value sequentially.
🐍 Real-World Example: Making juice: **map** slices all fruits in half, **filter** throws away any rotten pieces, and **reduce** presses them all together into a single glass of juice.
23. What is type hinting and why is it useful?
Type hinting allows you to explicitly declare expected data types for variables, arguments, and return values, improving code readability and enabling linters to catch bugs early. 
def greet(name: str) -> str:\n    return f"Hello, {name}"
🐍 Real-World Example: Labeling kitchen canisters with "Sugar" or "Salt". The jars work exactly the same way without labels, but it prevents you from making a terrible mistake with your morning coffee.
24. What is the difference between static methods and class methods?
- `@classmethod` receives the class (`cls`) as an implicit first argument, allowing it to inspect or modify class-wide properties.
- `@staticmethod` behaves like a regular isolated function inside the class namespace, receiving no implicit class or instance references.
🐍 Real-World Example: A car factory. A **class method** modifies the default paint color for all cars coming off the assembly line. A **static method** simply calculates a unit conversion like miles-to-kilometers.
25. What happens when an exception is raised but not caught?
Python pauses regular execution, prints a detailed trace history (traceback) detailing the error path to help with debugging, and terminates the script entirely.
🐍 Real-World Example: A fire alarm going off in a factory. If there is no automated safety system to handle it (try-except), the entire factory shuts down immediately to prevent further issues.

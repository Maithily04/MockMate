❓ JavaScript Interview Q&A

Click on any question to reveal answers and real-world examples.

1. What is the difference between `var`, `let`, and `const`?
- `var`: Function-scoped, can be redeclared, and is hoisted up with an initial value of undefined.
- `let`: Block-scoped, cannot be redeclared inside the same block, and is not initialized until its definition is evaluated.
- `const`: Block-scoped like let, but its value reference cannot be reassigned after declaration.
✨ Real-World Example: `var` is like a public noticeboard anywhere in the building. `let` is like writing a temporary note on a specific conference room whiteboard. `const` is carving a company name into stone at the lobby entrance.
2. Explain closures in JavaScript.
A closure is created when an inner function retains access to variables from its parent lexical scope, even after that parent function has finished executing. 
function outer() {\n  let count = 0;\n  return function inner() { return ++count; }\n}
✨ Real-World Example: A vending machine. The setup function finishes its job long ago, but the tracking button internally remembers how many snacks are left inside every time you click it.
3. What is Prototypal Inheritance?
Every JavaScript object possesses an internal private link pointing to a prototype object. Objects inherit properties and methods directly from this prototype link rather than copying them.
✨ Real-World Example: Renting a house with appliances. You don't own or buy the refrigerator yourself, but you have full access to use it because it belongs to the foundation model property you are linked to.
4. What is the Event Loop?
The Event Loop is a runtime mechanism that allows single-threaded JavaScript to perform non-blocking asynchronous operations. It continuously monitors the Call Stack and moves tasks from the Callback Queue onto the stack once it is empty.
✨ Real-World Example: A restaurant chef (Call Stack) cooking orders. An assistant handles taking reservations (Web APIs). When a reservation comes in, it waits in line (Callback Queue) until the chef finishes cooking the current dish and is ready to look up.
5. What is the difference between `==` and `===`?
`==` (loose equality) compares values after performing type coercion. `===` (strict equality) compares both the value and the exact data type without conversion.
✨ Real-World Example: Loose equality (`==`) sees a string item ticket `"5"` and a numeric weight value `5` and says they match. Strict equality (`===`) rejects it because a piece of text is not the same as a number.
6. What is Hoisting?
JavaScript's default behavior of moving variable and function declarations to the top of their current scope during the compilation phase before code execution begins.
✨ Real-World Example: An event coordinator preparing a stage line-up. Before the show starts, they gather all the microphones and setup stands at the front, even if the performers haven't walked out to use them yet.
7. How do Promises work and what are their states?
A Promise handles asynchronous operations, acting as a placeholder for a future result. It can be in one of three states: **Pending** (working), **Fulfilled** (success), or **Rejected** (error).
✨ Real-World Example: Ordering food at a fast-food counter. They hand you a digital buzzer device (Promise). It sits flashing (**Pending**) until your meal is ready (**Fulfilled**) or they run out of food and sound an alarm (**Rejected**).
8. Explain `async/await` syntax.
Built on top of Promises, it provides a cleaner, synchronous-looking syntax to handle asynchronous streams, eliminating complex chain patterns. 
async function fetchData() {\n  let response = await fetch(url);\n}
✨ Real-World Example: Sending a text message and waiting for a reply before typing your next thought, rather than leaving a long list of trailing voice messages.
9. What is Event Delegation?
Instead of attaching individual event listeners to dozens of specific child nodes, you attach a single listener to a shared parent element and use event bubbling to catch actions.
✨ Real-World Example: Instead of hiring 10 security guards to watch 10 separate office doors individually, you station one single guard at the main building exit gate to check everyone passing through.
10. What is the difference between Debouncing and Throttling?
- **Debouncing**: Delays execution until a specific amount of time has passed since the last event trigger.
- **Throttling**: Enforces a maximum rate limit, ensuring a function runs at most once every set time interval.
✨ Real-World Example: **Debouncing** is an elevator door waiting for people to stop walking in before closing. **Throttling** is a traffic light letting a batch of cars through exactly once every two minutes.
11. What is the meaning of the `this` keyword?
`this` refers to the object currently executing the function code block. Its value is determined entirely by *how* a function is called at runtime, not where it was written.
✨ Real-World Example: The word "me". If John says "Look at me", it refers to John. If Sarah says "Look at me", it refers to Sarah. It shifts based on who is speaking.
12. What are Arrow Functions and how do they handle `this`?
Arrow functions provide a shorter syntax and do not create their own `this` context. Instead, they inherit `this` lexically from their surrounding outer scope.
✨ Real-World Example: A drone camera tracking a tour group. It doesn't have an independent viewpoint of its own; it simply follows the direction and perspective of the group leader it belongs to.
13. What is the difference between `call`, `apply`, and `bind`?
- `call`: Invokes a function immediately, passing arguments one by one.
- `apply`: Invokes a function immediately, passing arguments as a single array container.
- `bind`: Returns a brand new function copy with its `this` context locked in, ready to be executed later.
✨ Real-World Example: Borrowing a car. `call` is driving it immediately using your own key accessories. `apply` is driving it with a packed suitcase of gear. `bind` is duplicating a permanent copy of the key so you can drive it next weekend.
14. Explain Currying in JavaScript.
A functional programming technique that transforms a function taking multiple arguments into a sequence of nested functions, each taking a single argument. 
const multiply = a => b => a * b;
✨ Real-World Example: An automated juice machine. First you lock in the fruit type (Apple), then it returns a new process waiting for you to select the size (Large) before dispensing.
15. What is the Temporal Dead Zone (TDZ)?
The period from the start of a block scope until a `let` or `const` variable is officially declared. Accessing the variable during this time throws a ReferenceError.
✨ Real-World Example: Waiting for a reserved table to be cleaned at a restaurant. The table physically exists, but you aren't allowed to touch it or sit down until the host officially invites you over.
16. What is the difference between `null` and `undefined`?
- `undefined`: A variable has been declared but has not been assigned a value yet.
- `null`: An intentional assignment representing the complete absence of any object value.
✨ Real-World Example: `undefined` is an empty unlabelled cardboard box waiting for contents. `null` is an empty box explicitly gift-wrapped and labeled "Nothing Inside".
17. What are Higher-Order Functions?
Functions that accept other functions as arguments, or return a function as their result (e.g., `map`, `filter`, `reduce`).
✨ Real-World Example: A factory manager. They don't do the physical labor themselves; instead, they hire specialized workers (callback functions) and distribute tasks down the line.
18. What is IIFE (Immediately Invoked Function Expression)?
A JavaScript function that runs automatically the moment it is defined, preventing internal variables from bleeding into the global scope. 
(function() {\n  // Isolated code\n})();
✨ Real-World Example: A self-destructing message envelope. You tear it open, read the information once, and it immediately burns away without leaving a trace on your desk.
19. Explain Rest and Spread operators.
They use the same syntax (`...`) but serve opposite purposes:
- **Rest**: Gathers multiple individual elements and condenses them into a single array.
- **Spread**: Unpacks elements from an array or object into individual items.
✨ Real-World Example: **Rest** is packing loose items lying around your room into a single travel bag. **Spread** is emptying that bag out onto a counter to display everything at once.
20. What is NaN and how do you check for it safely?
`NaN` stands for "Not-a-Number", resulting from invalid mathematical operations. You should check for it using `Number.isNaN()` because `NaN === NaN` surprisingly evaluates to false.
✨ Real-World Example: Trying to multiply a shoe size by a word like "apple". The operation fails, leaving you with an invalid calculation error.
21. What is strict mode (`"use strict"`)?
A configuration flag that opts the entire script into a strict parsing mode, turning silent errors into explicit exceptions and throwing errors on bad practices.
✨ Real-World Example: Working with a strict safety inspector watching over your shoulder. They won't let you leave loose tools lying around or skip steps without stopping the line immediately.
22. Explain the concept of Destructuring.
An efficient expression that lets you unpack values from arrays or properties from objects directly into distinct, clean variables. 
const { name, age } = user;
✨ Real-World Example: Reaching into a toolbox and grabbing just a hammer and a screwdriver directly, instead of rummaging through the entire box step-by-step.
23. What is the difference between deep and shallow object cloning in JavaScript?
A shallow clone copies top-level properties but shares references to nested objects. A deep clone creates an entirely separate copy of everything recursively.
✨ Real-World Example: Photocopying a registration form. A shallow copy copies the sheet but both sheets still point to the same physical locker key. A deep copy clones the key itself so you get a separate locker.
24. What are Generator Functions?
Functions that can pause their execution and resume later using the `yield` keyword, returning an iterator object.
✨ Real-World Example: Reading a book with a bookmark. You stop reading at chapter 3, close the book, and resume reading from that exact sentence when you return tomorrow.
25. Explain the distinction between Map and a plain Object.
A **Map** can use any data type (including functions or objects) as a key, tracks its size automatically, and maintains insertion order. A plain **Object** converts keys into strings or symbols and lacks built-in optimization for large data sets.
✨ Real-World Example: An object is like a simple coat rack where tags must be basic text hooks. A Map is an advanced automated valet garage system that can look up reservations using a digital token or physical card.

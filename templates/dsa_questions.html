❓ DSA Interview Q&A

Click on any question to reveal answers and real-world examples.

1. What is the difference between an Array and a Linked List?
Arrays use continuous slots for fast index lookups $\mathcal{O}(1)$. Linked Lists link separate objects dynamically.
💡 Real-World Example: An **Array** is like a row of reserved theater seats—everyone sits in order by seat number. A **Linked List** is like a scavenger hunt—each clue tells you where to find the next one, even if they are scattered all over the house.
2. Explain Big O Notation.
A mathematical metric defining the upper bounds of runtime or memory scalability.
💡 Real-World Example: If you need to send a file to a friend, sending it via email scales with file size ($\mathcal{O}(n)$). Flying the file to them on a flash drive takes the same amount of time regardless of how large the data is ($\mathcal{O}(1)$).
3. How do a Stack and a Queue differ?
Stacks follow Last-In, First-Out (LIFO). Queues follow First-In, First-Out (FIFO).
💡 Real-World Example: A **Stack** is like a stack of clean dinner plates—you always take the top one first. A **Queue** is like a line at an ATM—the first person to arrive is the first one served.
4. What is a Hash Collision?
When two unique keys yield identical hash index evaluations. Fixed by chaining or probing.
💡 Real-World Example: Two files assigned to the same alphabetized filing cabinet drawer because both of their titles start with the letter "B".
5. Difference between a Binary Tree and a BST?
BST enforces that left child values are smaller than the parent node, and right child values are larger.
💡 Real-World Example: A general corporate organizational chart is a **Binary Tree**. A well-organized digital dictionary directory where folders are strictly divided by alphabetical splits is a **BST**.
6. Explain Binary Search complexity.
Logarithmic sorting search splits $\mathcal{O}(\log n)$ by discarding half the items at each step.
💡 Real-World Example: Searching for a name in a physical phone book. You open up exactly to the middle, see if the target name comes before or after, and rip the wrong half of the book away. Repeat until you find the name.
7. What is a Priority Queue?
An extraction queue ordered by item priority weights rather than arrival times.
💡 Real-World Example: A hospital emergency room triage desk. A patient with a minor scrape waits behind a patient arriving later with a serious injury.
8. Contrast BFS and DFS.
BFS explores wide layer circles using queues. DFS dives deep into branches using stacks.
💡 Real-World Example: **BFS** is like a ripple radiating outward when you drop a pebble in water. **DFS** is like exploring a deep cave network, walking down a single tunnel until you hit a dead end before backtracking.
9. Explain Quick Sort.
Partitions elements dynamically around a chosen pivot to conquer sorting sets recursively.
💡 Real-World Example: A teacher sorting test scores by picking a random passing grade (say, 75) as a pivot, making all students with lower grades stand on the left and higher grades stand on the right, then repeating the process for each group.
10. What is a Balanced Tree?
A self-adjusting tree structure that minimizes its height to guarantee optimal operations in $\mathcal{O}(\log n)$ time.
💡 Real-World Example: A see-saw that automatically adjusts its pivot point when kids of different weights get on, preventing one side from being stuck on the ground.
11. What is Dynamic Programming?
Optimizes recursive overlapping problems by caching subproblem solutions.
💡 Real-World Example: If I ask you what $1+1+1+1+1$ is, you count and say 5. If I write another $+1$ on the board, you don't recount from scratch; you remember the previous result was 5, add 1, and instantly say 6.
12. Explain a Trie structure.
A prefix string character search tree optimized for text retrieval operations.
💡 Real-World Example: Google's search bar predicting text auto-completions as you type character by character.
13. How do you detect a cycle in a Linked List?
Use Floyd's fast/slow twin tracking pointer approach.
💡 Real-World Example: Two runners on a track. If the track is a straight line, the fast runner will never see the slow runner again. If the track is a loop, the fast runner will eventually lap the slow runner and run into them from behind.
14. What are Tree Traversals?
Inorder (Left-Root-Right), Preorder (Root-Left-Right), Postorder (Left-Right-Root).
💡 Real-World Example: **Inorder traversal** is like walking down a library aisle and reading book titles strictly from left to right in alphabetical order.
15. What is a Monotonic Stack?
A stack that keeps its elements strictly sorted to solve next-greater element problems efficiently in $\mathcal{O}(n)$ time.
💡 Real-World Example: A line of people at a box office window. If a very tall person arrives, everyone shorter standing behind them leaves because they can no longer see the window.
16. Explain a Graph.
A non-linear network consisting of nodes (vertices) connected together by relationships (edges).
💡 Real-World Example: LinkedIn. People are the vertices, and mutual connections are the edges linking them together.
17. Explain Binary Heaps.
Tree structures where parents always maintain priority superiority over their children.
💡 Real-World Example: A corporate hierarchy where the CEO sits at the top, and management values filter downward uniformly.
18. What is the Sliding Window technique?
Maintains a running window over a subarray to optimize nested loops into linear runtime.
💡 Real-World Example: A moving car dashboard camera that continuously captures and updates footage of just the last 10 seconds of road travel.
19. What is the Two-Pointer technique?
Uses two reference index locations simultaneously to process collections efficiently.
💡 Real-World Example: Checking if a word is a palindrome (like "radar") by having one finger check letters from the start while another finger checks letters from the end, moving toward the middle.
20. What is Disjoint Set Union (DSU)?
Tracks tracking clusters efficiently using Union and Find partition sets.
💡 Real-World Example: Merging smaller kingdoms into empires during medieval wars, and checking if two villages belong to the same king.
21. Merge Sort vs Quick Sort.
Merge Sort guarantees stable sorting. Quick Sort is an in-place sort that performs faster on average.
💡 Real-World Example: **Merge Sort** is like sorting a giant stack of mail by dividing it into small, manageable piles and then carefully merging them back together in order.
22. Adjacency Matrix vs List.
Matrices use fixed 2D configurations. Lists use dynamic linked track spaces to optimize sparse graphs.
💡 Real-World Example: An **Adjacency Matrix** is a grid tracking flight routes between every city in the world (mostly empty zeros). An **Adjacency List** is an address booklet listing just the destinations you can actually fly to from each airport.
23. What is Amortized Time Complexity?
The average cost of an operation over a long sequence, accounting for rare high-cost steps.
💡 Real-World Example: Paying a low monthly rent fee for your apartment, punctuated by a rare, expensive annual security deposit update. The average cost per day remains low and predictable.
24. Explain Dijkstra's Algorithm.
Finds the shortest paths between nodes in a weighted network graph.
💡 Real-World Example: Google Maps calculating the absolute fastest driving route to your destination, accounting for traffic delays on different roads.
25. Recursion vs Iteration.
Recursion uses a self-calling structure. Iteration repeats actions linearly using explicit loops.
💡 Real-World Example: **Recursion** is like Russian nesting dolls—you open a doll to find a smaller version inside until you reach the smallest doll. **Iteration** is like counting down steps on a ladder one by one.
